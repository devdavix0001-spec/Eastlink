# Eastlink & Partners Developers LLC — Phase 1

A responsive, single-page corporate homepage for Eastlink & Partners Developers LLC. This phase intentionally has one public page at `/`; other pages, listings, verified project entries, testimonials, content management and enquiry storage remain future work.

## Run locally

Requires Node.js 18 or newer. Run `npm run dev` to serve the site on port 3000. Run `npm run build` to write a deployable static site to `dist/`.

## Content integrity

The project and property areas are clearly labelled as placeholders. The architectural images are illustrative references and are not presented as Eastlink projects or property inventory. The logo is extracted from the supplied screenshot and preserved without redesign.
